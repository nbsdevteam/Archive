feat(e2e): enhance cypress testing stability with data-testids

Added comprehensive data-testid attributes to eliminate fragile
position-based selectors in E2E tests.

Component Changes:
- SelectField: Added data-testid prop support for react-select targeting
- UploadDocumentTargetSection: Added testids to all dropdowns
  (upload-kind, department, document-type, folder, confidentiality)
- UploadDocumentFileSection: Added testid to file input
- EditDocumentFormContent: Added testids to all edit form dropdowns

Cypress Spec Updates:
- walkthrough-slow.cy.ts: Replaced .react-select__control.eq(N) with data-testids
- slow-smoke-real-api.cy.ts: Updated to use direct field targeting
- slow-smoke-production-safe.cy.ts: Migrated all selectors to data-testids
- documents-create.cy.ts: Updated upload form selectors
- documents-bulk-upload.cy.ts: Updated bulk upload selectors

Benefits:
- Tests no longer break when form field order changes
- Clear intent in test code (field name vs position)
- Resilient to UI refactoring and CSS changes
- Improved test maintainability and debugging

All existing data-testids verified and documented in
CYPRESS_E2E_IMPROVEMENTS.md
